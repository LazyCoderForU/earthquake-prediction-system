## Overview
The **Earthquake Prediction System** leverages historical earthquake data to identify patterns and predict future seismic events. This project is designed to assist researchers and disaster management teams in understanding earthquake trends.

## Dataset
The project uses the **Significant Earthquake Dataset (1900-2023)**, which contains detailed information about significant earthquakes over the past century. The dataset includes:
- Date and time of the earthquake
- Magnitude
- Location (latitude and longitude)
- Depth
- Other relevant metadata

The dataset file is located in this repository as:
- `Significant Earthquake Dataset 1900-2023.csv`

## Features
- Data preprocessing and visualization
- Machine learning models for earthquake prediction
- Interactive Jupyter Notebook for experimentation
- Insights into earthquake trends and patterns
